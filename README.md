# Oh My Archy

My personal, idempotent Ruby-based setup for customizing **Omarchy** (Arch Linux + Hyprland).

This repository keeps your customizations safe from Omarchy updates and makes them easy to apply on a fresh install or after an update.

## Setup & Usage
clone repository and navigate to the repostitory directory.

```
cd oh-my-archy
```

Run setup

```
ruby setup.rb
```
